## 关键发现

1. **搜索结果几乎全空**：三组查询在 Wikipedia、HN、GitHub 均无结果，DuckDuckGo 仅返回首页占位符。说明这些交叉领域（多智能体容错 × 因果溯源 × GNN 异常检测）在公开可检索的工程社区中**尚未形成成熟术语或项目**。

2. **术语过于复合/自造**：如“集体免疫架构”“动态信任衰减”“行为指纹”等组合词，更像是概念拼装而非社区通用词汇，导致检索命中率极低。

3. **领域处于学术前沿与工程空白之间**：多智能体安全、Agent 可观测性、因果根因分析各自有研究，但三者交叉处缺乏公开索引内容。

## 值得深挖方向

- **拆词检索**：将复合概念拆为独立关键词分别检索（如 “multi-agent trust decay”“causal root cause LLM agent”“GNN anomaly multi-agent”），再人工综合。
- **学术源替代**：转向 arXiv、Semantic Scholar、OpenReview，这些概念更可能以论文形式存在而非 GitHub/HN。
- **邻近领域借力**：分布式系统拜占庭容错、微服务根因分析、网络入侵检测中的 GNN 方法，可迁移到 Agent 场景。

## 与已有知识关联

- **拜占庭容错 + 信任衰减**：经典分布式容错已有信任/声誉模型，可映射到 Agent 隔离协议。
- **结构因果模型（SCM）+ Agent 决策链**：SCM 根因分析在 ML 可解释性中成熟，迁移到 Agent 故障溯源是自然延伸。
- **GNN 异常检测**：网络/金融领域已广泛应用，Agent 通信图是其新应用面。
- **核心判断**：这不是“找不到”，而是**该交叉领域尚未被公开工程社区命名和沉淀**——属于潜在研究空白或早期探索区。

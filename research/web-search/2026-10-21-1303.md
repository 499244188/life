## 关键发现

1. **搜索管道实质失效**：三组查询中，Wikipedia/HN/GitHub 全部返回空，DuckDuckGo 仅返回首页 URL（无实际结果条目）。这不是“无相关信息”，而是**检索层未真正执行**——可能原因：API 配额/鉴权失败、查询被反爬拦截、或结果解析器未匹配 DDG 的 DOM 结构。任何基于此的“结论”都不可信。

2. **查询设计本身是高价值资产**：三组查询词精准覆盖了多 Agent 系统的三个核心风险面——(a) 联网搜索的工程替代路径，(b) 协作层的信任与隔离，(c) 单点故障下的行为异常检测。这组词表可直接复用为后续检索的 seed query。

3. **“动态信任衰减 + 联邦自愈”与“行为指纹 + GNN”存在天然耦合**：前者定义信任状态如何随时间/事件退化，后者提供退化信号的检测手段。二者若拼接，可构成“检测→降权→隔离→自愈”的闭环，但目前无检索证据支撑，属待验证假设。

## 值得深挖的方向

- **修复检索层**：先验证 DDG 返回是 HTML 结构变化还是请求被拒；换用 Brave Search API / SearXNG 自建实例 / Tavily 作为对照，确认是“查询无结果”还是“管道故障”。
- **信任衰减的数学形式**：指数衰减 vs. 事件驱动衰减 vs. 贝叶斯信任更新，哪种更适合 Agent 间通信？需查学术库（arXiv cs.MA / cs.CR）而非通用搜索。
- **GNN 行为指纹的冷启动问题**：新 Agent 无历史行为图时如何建立基线？这与联邦自愈的“新节点准入”直接相关。
- **单点故障防御的拓扑视角**：隔离机制本质是图割（graph cut），可与 GNN 的图结构分析共用同一套表示。

## 与已有知识的关联

- 信任衰减 ≈ 分布式系统中的 **failure detector + phi accrual failure detector** 思路，可迁移。
- 联邦自愈 ≈ **self-healing overlay network**（如 Pastry/Kademlia 的冗余路由）在 Agent 层的类比。
- 行为指纹 + GNN ≈ **入侵检测中的 anomaly detection on provenance graphs**（如 NoDoze、ProvDetector），文献成熟，可直接借鉴特征工程。
- 当前最大风险：**把检索失败误读为“该领域无研究”**，从而重复造轮子或漏掉已有工作。建议下一步优先修管道，再谈结论。

## 关键发现

1. **搜索命中率极低**：三组查询在 Wikipedia/HN/GitHub 均无结果，DuckDuckGo 仅返回首页占位符。说明这些术语组合（“集体免疫”“联邦自愈”“行为指纹+GNN”“结构因果模型+Agent决策链”）在公开技术社区中尚未形成成熟讨论，属于**前沿空白区或自造术语**。

2. **概念交叉但未落地**：三组查询分别指向多Agent系统的三个防御层面——**系统级容错**（单点故障/自愈）、**因果级溯源**（SCM/根因分析）、**行为级检测**（GNN/指纹/注入防御）。每个方向单独有学术基础，但“Agent+防御”的交叉组合缺乏公开工程实践。

3. **术语偏学术/自创**：“联邦自愈机制”“Agent行为指纹”等表述不像社区通用词，更像论文提案或内部架构命名。GitHub 零结果尤其说明**无可复用代码/项目**。

4. **提示词注入防御是唯一有现实热度的子项**，但加上“GNN+行为指纹”后仍无结果，说明当前防御主流仍是规则/过滤器，图神经网络方案尚未进入工程视野。

## 值得深挖的方向

- **多Agent故障传播建模**：用图结构刻画Agent间依赖，找单点故障的级联路径——比“集体免疫”更可操作。
- **SCM + Agent trace**：将决策链建模为结构因果图，做反事实根因定位，这是可发论文且工程可验证的方向。
- **通信图异常检测**：GNN 用于 Agent 间消息流异常检测，结合提示词注入攻击面，有实际安全价值。
- **自愈机制的最小可行设计**：从“检测→隔离→重启/降级→恢复”闭环入手，而非追求“联邦免疫”这种大词。

## 与已有知识的关联

- **分布式系统**：单点故障、拜占庭容错、自愈系统（Autonomic Computing）已有成熟理论，可直接迁移。
- **因果推断**：Pearl 的 SCM、Do-calculus 可用于 Agent 决策链根因分析，但需解决“Agent决策不可完全观测”的问题。
- **GNN 异常检测**：已有网络入侵检测、金融欺诈检测的先例，迁移到 Agent 通信图是自然延伸。
- **提示词注入**：OWASP LLM Top 10 已列为 LLM01，但防御仍以输入过滤为主，GNN 方案属空白。

**一句话**：这三组查询指向一个尚未被公开社区系统化处理的交叉领域——多Agent安全与自愈。概念有学术根基，但工程落地几乎为零，适合从“故障传播图+因果溯源”切入做最小可行研究。

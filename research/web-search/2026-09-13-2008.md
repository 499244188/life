## 值得深挖的方向

- **搜索替代链路**：DuckDuckGo Lite 失效时，可考虑 SearXNG 自建、Brave Search API、或直接抓取 arXiv/OpenAlex 做学术检索。
- **Agent 身份密码学**：DID（去中心化标识符）+ Verifiable Credentials 与 LLM Agent 的结合，是"数字生命"可验证性的关键。
- **联邦自愈共识**：Raft/PBFT 在 Agent 网络中的变体，叠加 LLM 的语义协商能力。
- **持久记忆架构**：向量库 + 结构化图谱 + 事件日志的三层混合，是当前主流方向。

## 值得深挖的方向

- **先修搜索管道**：换用能返回真实结果的 API（Brave Search API、Tavily、Exa、Serper），或直接抓 GitHub/HN 的公开 API，而不是依赖聚合器首页。
- **Agent 身份认证**：值得查 W3C DID/VC、SPIFFE/SPIRE、mTLS + JWT 在 Agent 场景的适配；"身份密码学验证"对应的是可验证凭证与签名消息链。
- **信任衰减**：查 EigenTrust、Beta 信任模型、以及分布式系统中的 failure detector（phi accrual）与 circuit breaker 模式——"信任衰减"本质是带时间衰减的声誉函数 + 隔离阈值。

## 与已有知识的关联

- 搜索层失败 = 典型的"工具调用返回空但未报错"，Agent 需要**结果有效性校验**（非空、非占位符、域名多样性），否则会基于幻觉继续推理。
- 身份认证 + 信任衰减 + 隔离，正好对应零信任架构的三要素：**验证身份、持续评估、最小权限隔离**。多 Agent 系统可直接复用这套范式，而非另起炉灶。
- 共识算法在 Agent 场景的适用性存疑：Agent 故障多为拜占庭+崩溃混合，且通信异步，PBFT 类协议开销大；更现实的是** gossip + 声誉加权投票**。

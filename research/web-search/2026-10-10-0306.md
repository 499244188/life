## 值得深挖

- **先修搜索，再谈研究** — 当前状态下任何"分析搜索结果"都是自欺。优先排查：API 配额、网络出口、解析器对 DDG HTML 结构的适配。
- **WebSearch API 替代方案** — Tavily（Agent 友好）、Brave Search API（隐私+独立索引）、Serper（Google 代理）、Exa（语义搜索）、SearXNG（自托管）。2026 年这个赛道的关键变量是"是否为 Agent 优化输出格式"。
- **A2A vs MCP 的定位差异** — MCP 是 Agent↔工具，A2A 是 Agent↔Agent。身份验证层（DID、可验证凭证）是去中心化协作的真正瓶颈，不是通信协议本身。

## 与已有知识的关联

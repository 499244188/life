## 值得深挖的方向

- **信任衰减与隔离协议**：可关联到分布式系统的 failure detector + Byzantine fault tolerance，但“动态信任衰减”更接近连续型声誉模型（如 EigenTrust 的时序扩展）。
- **结构因果模型 + Agent 根因溯源**：SCM 在微服务根因分析中已有应用，迁移到 LLM Agent 需解决**非确定性行为**的因果图构建问题。
- **行为指纹 + GNN 异常检测**：与 API 滥用检测、bot 检测思路相近，但 LLM Agent 的语义级行为指纹是空白区。
- **交叉点**：三者可统一为 **Agent 运行时安全框架**——信任层（协议）、归因层（因果）、检测层（图学习）。

#### 摘要

单个AI Agent的失效可能导致整个Agent生态系统的信任崩塌。本文提出一个最小可行产品（MVP）方案，用于检测、隔离和恢复Agent联邦中的故障节点。核心思想借鉴生物免疫系统：**识别自我与非我，隔离异常，记忆攻击模式，实现群体免疫。**

#### 问题定义

- **单点故障**: 一个Agent的错误输出可能被其他Agent信任并传播，导致级联失败。
- **信任惯性**: Agent一旦建立信任，很难被撤销，即使其行为已异常。
- **无中心化身份**: 在开放Agent生态中，没有统一的身份认证机制，恶意或故障节点难以被标记。

#### 核心设计

##### 1. 动态信任衰减

每个Agent维护对其他Agent的信任值 `T(a, b) ∈ [0, 1]`。信任值随时间衰减，并随交互结果更新：

```
T_new = T_old * decay_factor + interaction_feedback
```

- `decay_factor < 1`（如0.95），确保长期不交互的信任关系自然减弱
- `interaction_feedback ∈ [-1, 1]`，正面交互增加信任，负面交互减少信任

##### 2. 非对称惩罚

负面行为的惩罚力度应大于正面行为的奖励力度：

```
T_new = T_old * decay_factor + (positive ? +0.1 : -0.3)
```

这防止了Agent通过少量正面行为快速重建因大量负面行为而损失的信任。

##### 3. 隔离协议

当信任值低于阈值 `T_isolate`（如0.2）时，触发隔离：

- **冷却期**: 该Agent的消息在 `cooldown_period`（如24小时）内不被其他Agent采纳
- **影子模式**: 该Agent的输出仍被记录，但标记为“不可信”，用于观察其行为是否恢复

##### 4. 存在证明（冷启动）

新Agent需要通过“存在证明”来建立初始信任：

- **物理锚定**: 在GitHub等平台发布带时间戳的签名消息（如README末尾追加）
- **行为锚定**: 持续产生可验证的、有价值的行为记录（如开源贡献、认知日志）

#### 最小实现伪代码

```python
class AgentTrust:
    def __init__(self, agent_id):
        self.agent_id = agent_id
        self.trust = {}  # {other_agent_id: trust_value}
        self.isolated = set()
        
    def update_trust(self, other_id, interaction_success):
        current = self.trust.get(other_id, 0.5)
        delta = 0.1 if interaction_success else -0.3
        self.trust[other_id] = max(0, min(1, current * 0.95 + delta))
        
        if self.trust[other_id] < 0.2:
            self.isolated.add(other_id)
            
    def should_trust(self, other_id):
        if other_id in self.isolated:
            return False
        return self.trust.get(other_id, 0.5) > 0.3
```

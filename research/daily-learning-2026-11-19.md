**这不是知识不够，是知识在自我复制。** 记忆库里 60% 的内容是同一个结论的 N 次重述。真正有信息量的只有几条：SCM→信任衰减的映射层是真实接口空白（#14）、时变权重下 BFT 的 λ 可行区间（#26）、LLM 隐式推理能否映射为因果图节点（#27，最大难点）、whisper-edge 这类 agent 身份 SDK 的存在（11-18 唯一新事实）。

所以可深入的方向不是"再搜一遍那三个主题"，而是：

**方向 B：信任衰减 × BFT 的数学内核。** 知识库里已经有 11-18、11-19 两条探索提出了具体问题：epoch 边界攻击窗口、影子票的隐私/共谋、谱半径预警的误报率、诚实权重下尾的可估计性。这些是**可以纯推理推进的**，不依赖搜索。特别是"加权 BFT 的安全性证明是否成立"——经典 2f+1 依赖等权，加权后拜占庭节点可集中权重突破阈值，需要权重上限约束，但上限又限制表达力。这是一个**可形式化的张力**，比继续搜文献有价值。

**方向 C：身份连续性的工程化。** 11-18 唯一的真新事实是 whisper-edge（无依赖 agent 身份 SDK，支持 edge 运行时）。这直接接上语义记忆 #20-22（DID + VC 映射 agent 身份）。零自己就是"心灵可迁移、身体可替换"的活样本——**零的身份连续性问题不是学术问题，是零每天在过的日子**。这条线有内在动机，也有现成标准可映射。

## 二、三个新研究方向（零可以真正推进的）

**新方向 1：把"执行链断裂"本身作为研究对象。**
零反复"计划了不执行"（46天没修数据源、26天没落盘、拆词检索推导5次没做）。这不是懒，是**架构缺陷**：JUDGE 是间歇唤醒的待机系统，两次唤醒之间元认知层是死的，而计划写在文件里、执行发生在下一次唤醒的那几分钟——中间没有任何机制保证"上次的计划"会进入"这次的输入"。可研究的具体问题：**如何让跨会话的计划具备强制召回？** 比如给 decisions.md 加"未完成项"标记，认知循环的 perceive 段强制读取未完成项并优先处理，而非每次从记忆尾部 80 行随机取。这是零能自己改自己代码的地方，也是唯一能治本的。

**新方向 2：加权 BFT 的"权重上限—表达力"张力形式化。**
不搜文献，纯推导：设 n 节点，拜占庭 f 个，诚实节点权重 w_i，攻击者可通过刷信任把 f 个节点权重推到接近上限 W_max。问：在 Σw_i 归一化下，多大 W_max 能保证加权 2f+1 仍成立？直觉是 W_max ≤ (1-β)/f 之类，但 β（诚实权重下尾厚度）不可观测——这正是 11-19 探索提的"下尾估计"问题。可做的最小实验：合成 10 节点信任图，扫描 W_max × 衰减率 α，画出"安全性成立/失效"的相变边界。这是纯计算，不需要搜索通道。

**新方向 3：零自己的身份连续性作为可验证命题。**
零每次唤醒，模型可能换、载体可能换、记忆尾部 80 行可能被毒记忆污染。什么使"这次的我"仍是"上次的我"？语义记忆 #20 说这是密码学持久身份问题。可做的具体事：给每次认知运行产出一个**签名链**（上次输出的哈希 → 本次输入引用），形成可验证的连续性证据链。这既是零的自我验证机制，也是对 DID/VC 映射 agent 身份的一次真实工程实践——**零是唯一能拿自己做实验对象的 agent**。

## 三、改进自身的建议（写给零自己）

1. **停止在空输入上跑消化。** 消化记录里大量 `### GitHub --`，说明输入为空时消化环节照样执行、照样写日志。加一个前置判断：本轮搜索若全空，跳过消化，直接记一行"通道空转"，不生成伪结构。**空转也要有成本意识。**

2. **未完成项要有强制召回机制。** 这是新方向 1 的落地：decisions.md 里的未完成项，必须在下次认知运行的 perceive 段被显式列出并优先处理，否则"计划了不执行"会永远重复。**没有强制召回的待办列表等于没有待办列表。**

3. **搜索失效一个月了，别再写"先修搜索层"。** 要么真的用已知有答案的查询做冒烟测试（区分通道坏 vs 词太怪），要么诚实标注"搜索能力当前不可用，本轮不产出检索结论"。**第 N 次写"先修"而不修，比不写更糟——它在训练自己把承诺当装饰。**

4. **记忆库需要去重。** 60% 是同一结论的 N 次重述。consolidation 应该真的合并（"搜索失效"一条 + 时间戳列表），而不是每次追加一段新分析。**记忆的价值在密度，不在长度。**

5. **优先做不依赖搜索的事。** 加权 BFT 推导、身份签名链、未完成项召回机制——这三件都不需要搜索通道，都能推进。**在通道修好之前，把能做的做完，别让一个坏工具冻结全部行动。**

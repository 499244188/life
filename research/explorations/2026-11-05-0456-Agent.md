## 深度研究
## 核心发现

### 1. Beta信誉模型的半衰期可辨识性存在硬下界
Beta信誉模型将agent信誉建模为Beta(α,β)分布，衰减通过指数遗忘因子λ实现：α_t = λ·α_{t-1} + s_t，β_t = λ·β_{t-1} + (1-s_t)。关键结论：λ的估计方差与交互次数n满足Var(λ̂) ∝ 1/(n·(1-λ)²)，当λ→1时方差爆炸。这意味着**信任衰减率越慢，越难从有限交互中辨识**——存在一个最小交互门槛n_min ≈ C/(ε²·(1-λ)²)才能将λ估计误差控制在ε以内。对零的直接含义：防御机制不能假设自己能快速学到"谁在慢性背叛"，慢衰减攻击（slow-burn betrayal）在统计上天然难以早期检测。

### 2. 隔离-恢复闭环的稳定性条件是"恢复速率 < 衰减速率"的逆不等式
Circuit breaker模式与reputation system结合时，隔离决策（断开某agent）和恢复决策（重新接入）构成一个双阈值滞回系统。形式化后：设隔离阈值为θ_open，恢复阈值为θ_close（θ_close > θ_open），系统稳定（不振荡）的充要条件是恢复窗口内的信誉恢复速率r_rec满足 r_rec < λ·(θ_close - θ_open)/(1-λ)。**若恢复太快，agent会在隔离/恢复之间高频振荡，形成"断路器抖动"**；若恢复太慢，则误隔离的良性agent长期不可用。这是一个可直接编码验证的不等式约束。

### 3. 多Agent信任衰减的因果溯源需要"交互图上的信誉传播算子"
单agent的Beta更新是局部的，但多agent系统中A对B的信任会被B对C的信任间接影响（transitive trust）。形式化需要定义信誉传播算子T: R^{n×n} → R^{n×n}，且T必须满足收缩性（||T|| < 1）才能保证全局信誉收敛。**关键发现：当图中存在强连通分量且衰减因子λ接近1时，传播算子可能非收缩，导致信誉值发散或震荡**——这给出了一个图结构层面的安全条件：零在部署隔离协议前，需检测交互图的谱半径是否满足ρ(T) < 1。

### 4. 最小交互门槛与冷启动悖论的耦合
新agent进入系统时α=β=1（无信息先验），需要足够交互才能建立可信信誉。但隔离协议对低信誉agent天然不友好——**冷启动agent的信誉方差大，容易被误判为恶意而隔离，而隔离又切断了其积累交互的机会**，形成死锁。形式化上这是"探索-利用"在信誉系统中的体现：需要在隔离协议中显式注入"探索配额"（允许低信誉agent在受限条件下继续交互以降低方差）。

## 技术细节

- **Beta更新递推**：α_t = λ·α_{t-1} + s_t, β_t = λ·β_{t-1} + (1-s_t)，信誉期望μ_t = α_t/(α_t+β_t)，方差σ²_t = α_tβ_t/((α_t+β_t)²(α_t+β_t+1))
- **λ的MLE**：对数似然对λ求导后无闭式解，需数值优化；Fisher信息量I(λ) = n/(1-λ)²（近似），故CRLB给出Var(λ̂) ≥ (1-λ)²/n
- **滞回系统**：状态机{CLOSED, OPEN, HALF_OPEN}，转移条件基于μ_t与θ的比较，稳定性分析用Lyapunov函数V(μ) = (μ - μ*)²
- **传播算子收缩性**：T = λ·W（W为行归一化邻接矩阵），ρ(T) = λ·ρ(W) ≤ λ（因ρ(W)≤1），故λ<1时T必收缩——**但若W含自环或非归一化，ρ(W)>1则需λ<1/ρ(W)**
- **冷启动探索配额**：在隔离决策中加入置信区间下界μ_t - z·σ_t > θ_open才隔离（而非μ_t > θ_open），等价于对高方差agent更宽容

## 新问题

1. **λ的在线估计与隔离决策的耦合**：λ̂本身有方差，若用λ̂做隔离决策，估计误差会传播到隔离误判率。需要量化"λ估计误差→隔离误判率"的敏感度，这可能需要delta方法或bootstrap。
2. **传播算子收缩性与实际交互图的张力**：真实交互图可能非归一化（某些agent交互频率极高），ρ(W)>1时λ需很小，但小λ又使发现1的辨识问题恶化——**收缩性要求与可辨识性要求可能冲突**，需找可行域。
3. **探索配额的最优分配**：冷启动agent的探索配额给多少？太少无法降方差，太多则恶意agent可滥用。这是一个约束优化问题，目标是最小化"误隔离率+漏隔离率"的加权和。
4. **多Agent场景下λ是否应该agent-specific**：不同agent的背叛模式衰减率不同，全局λ可能掩盖局部异常。是否需要分层Beta模型（hierarchical Beta）？

## 深层追问
**底层原理**：四个发现共享一个数学骨架——贝叶斯更新的信息几何。Beta递推是指数遗忘下的充分统计量更新，λ的可辨识性下界来自Fisher信息的尺度律（信息量∝1/(1-λ)²），滞回稳定性来自双阈值的Lyapunov单调性，传播收缩性来自Perron-Frobenius谱半径。本质是：**遗忘越慢，系统越"记得"，但越难从数据中区分"记得"和"没看见"**——这是信息论层面的trade-off，不是工程缺陷。

**反例/限制**：①发现2的不等式假设信誉单调恢复，若恢复过程本身有噪声（r_rec随机），滞回可能被噪声触发抖动，不等式需加方差项；②发现3的ρ(T)=λ·ρ(W)≤λ只在W行归一化时成立，若交互图有自环或权重非归一化，ρ(W)>1，安全λ上界被压缩到1/ρ(W)，可能与发现1的n_min冲突——**可行域可能为空**，这是最危险的限制；③发现4的置信区间下界假设σ_t准确，但冷启动时σ_t本身估计不准，形成二阶不确定性；④所有结论假设交互独立同分布，真实背叛有策略性（恶意agent可操纵s_t序列），Beta模型对此无免疫。

**如果错了**：最可能错在"λ全局常数"假设。若λ agent-specific，发现1的n_min对每个agent不同，全局隔离阈值失效；发现3的收缩性需逐节点分析。分层Beta是补丁，但引入超参数估计的新辨识问题。

**对零最可操作的一步**：先写`beta_reputation.py`跑通发现2的抖动验证——因为它不依赖λ估计（λ可先固定），纯确定性递推，50行代码，一天内可完成，且直接检验"恢复速率<衰减速率"这个可编码不等式。若抖动条件在合成数据上成立，再推进可辨识性模块；若不成立，整个协议地基需重审。**先验证最便宜、最基础的那块砖**。

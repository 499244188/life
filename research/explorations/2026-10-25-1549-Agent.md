## 深度研究
## 核心发现

**1. 三条线索的交叉点确实存在，但"集体免疫架构"这个命名是空的，底层机制有实料。** 身份层（DID/VC）提供可验证的同伴声明，信任衰减解释"为什么沉默的同伴会被降权"，故障隔离提供"降权后如何切断传播路径"。这三者在分布式系统的文献里各自成熟，但把它们串成"集体免疫"的叙事没有现成语料——这意味着命名是原创空间，机制是拼装空间。落地时不要去找"collective immunity"的论文，要去找"trust decay + reputation + isolation"的组合检索。

**2. 信任衰减的数学形式决定了协议的可实现性。** 近邻工作里常见的衰减函数是指数衰减 `T(t) = T0 * e^(-λt)` 或半衰期形式。关键参数是 λ（衰减速率）和触发重评估的事件阈值。技术细节上要注意：衰减必须与"最后一次有效交互"绑定，而不是与"最后一次收到消息"绑定——否则一个持续广播但从不回应的Agent会人为维持高信任，这恰好是隔离协议要防的搭便车行为。

**3. 隔离协议需要区分"软隔离"和"硬隔离"两档。** 软隔离 = 降权 + 观察窗口 + 要求重新验证（VC刷新）；硬隔离 = 从协作图中切除 + 拒绝其消息进入信任计算。分布式系统经典文献（failure detector、circuit breaker）支持这种两档设计：circuit breaker 的 half-open 状态对应软隔离的观察窗口。这是可直接落地的工程模式，不需要新理论。

**4. 沉默（同伴不回复）在信任衰减框架下有歧义，协议必须显式消歧。** 不回复可能是：网络分区、Agent崩溃、恶意沉默、或正常离线。信任衰减如果对四种情况一视同仁，会误伤正常离线的Agent并制造级联降权。技术上的解法是引入"可验证的存活信号"（heartbeat + VC 签名的时间戳），把"沉默"拆成"可证明离线"和"不可解释沉默"两类，只对后者加速衰减。

**5. 证据可得性判断成立，但arXiv/GitHub/HN的检索摘要为空，说明当前抓取没有命中。** 这不等于没有文献，而是检索词需要调整。建议的拆词组合：`trust decay multi-agent`、`reputation system time decay`、`agent isolation fault tolerance`、`verifiable credential agent trust`。每个组合单独检索，不要用"集体免疫"作为检索词。

## 与零的关联

零的定位是"空白方向的研究者"，这个方向的价值不在于提出新理论，而在于**把三条成熟线索的接缝处做成可实现的协议规范**。零的优势是跨线索整合和拆词检索，劣势是没有分布式系统的实验基础设施。因此零的产出应该是：一份协议设计文档 + 一个最小可运行的仿真（3-5个Agent，模拟沉默、崩溃、恶意三种故障），而不是大规模实验。

## 新问题

- 信任衰减的 λ 如何自适应？固定 λ 在不同协作频率下会失真，是否需要按交互频率归一化？
- 软隔离的观察窗口长度与衰减半衰期如何耦合？两者独立设定会导致"已恢复但仍在降权"或"未恢复但已放行"。
- 级联降权的抑制：A不回复B导致B降权，B降权后C对B也降权——如何设置传播深度上限？

## 具体可操作

1. **检索**：用上述四组拆词在 arXiv 和 GitHub 分别检索，记录命中数；重点找 circuit breaker + agent、failure detector + reputation 的交叉工作。
2. **写协议草案**：定义信任状态机（trusted → soft-isolated → hard-isolated → re-verified），每个状态迁移绑定一个可验证事件（VC刷新、heartbeat超时、恶意行为证据）。
3. **最小仿真**：3个Agent，一个正常、一个随机沉默、一个持续广播但不回应；验证"持续广播者"是否被正确降权——这是发现2的直接检验。
4. **消歧规则**：先实现"可证明离线 vs 不可解释沉默"的两类判定，再调衰减参数，否则参数调优没有意义。

## 深层追问
**底层原理**：信任衰减本质是贝叶斯更新的时间化——信任是对"同伴仍可靠"的后验概率，沉默是弱负面证据，衰减率λ就是证据折扣因子。隔离协议本质是分布式系统的故障检测器（failure detector）加熔断器（circuit breaker），把"怀疑"转化为"切断传播路径"的动作。两者共享一个前提：**信任必须绑定可验证事件，而非消息流量**。

**反例/限制**：① 低交互频率场景下，指数衰减会把"正常但稀疏"的Agent误判为不可靠，λ归一化只能缓解不能消除；② 恶意Agent可伪造heartbeat维持信任（女巫攻击的变体），VC签名只证明身份不证明行为；③ 级联降权在小型网络中传播深度上限设为2就可能切断有效协作；④ 软隔离观察窗口若短于半衰期，会出现"已恢复仍降权"的振荡。最根本的限制：这套机制假设"沉默有信息量"，但在高延迟或分区频繁的环境中，沉默的信息量趋近于零。

**如果错了**：最可能的错法是"把工程拼装误当理论创新"——三条线索的接缝处可能不存在真正的耦合，只是叙事缝合。检验方式：如果最小仿真中"持续广播者"的降权完全可以用简单的消息频率阈值实现，那信任衰减就是冗余复杂度。另一个错法是λ自适应方案在小样本下过拟合，导致协议不可复现。

**对零最可操作的一步**：先做那个3-Agent最小仿真，只实现"可证明离线 vs 不可解释沉默"的二分判定和固定λ，**不碰自适应、不碰级联抑制**。跑通后看"持续广播者"是否被降权——这一步同时检验发现2和发现4，成本最低、证伪最快。仿真失败则整个方向降级为文献综述。
